# 인스타그램 캐러셀 만들기

인스타그램에 올릴 캐러셀 게시물 1개를 만든다. 먼저 문구와 캡션을 만들어 확인받고, 확인받은 뒤에 주제에 어울리는 색으로 이미지를 만든다. 인스타그램에 직접 올리지는 않는다.

## 주제
- 사용자가 주제를 주면 그 주제로 쓴다.
- 주제가 없으면 "시니어프로보노가 알려 주는 정부지원, 일자리, AI·스마트폰 활용법, 건강, 여행, 생활정보 팁" 안에서 고른다.
- 쓰기 전에 `carousel` 폴더의 기존 게시물을 읽고 이미 다룬 소재는 피한다.
- 사용자가 "블로그 글로", "스레드 글로", "쇼츠 대본으로" 캐러셀을 만들어 달라고 하면 `blog`, `threads`, `shorts` 폴더의 해당 글을 바탕으로 쓴다.

## 장 구성 (7~10장)
1. **1장 (표지)**: 넘기고 싶게 만드는 제목 한 줄 + 짧은 부제. 질문이나 "OO 하는 법 3가지"처럼 무엇을 얻는지 바로 보이게.
2. **2장**: 왜 알아야 하는지, 공감되는 상황 하나.
3. **본론 (3장~)**: 한 장에 내용 하나. 따라 할 수 있게 순서·버튼 이름·실제 입력 문장을 적는다.
4. **끝에서 두 번째 장**: 한눈에 보는 요약.
5. **마지막 장**: 저장·팔로우·댓글을 부르는 한마디 (예: "나중에 보려면 저장해 두세요").

## 글자 규칙 (휴대폰에서 한눈에)
- 한 장에 제목 1줄(15자 안팎) + 본문 최대 3줄(한 줄 18자 안팎).
- 글자는 크게: 1080 × 1350 기준 제목 72px 이상, 본문 44px 이상.
- 인스타그램은 올릴 때 사진을 정사각형(1080×1080)으로 잘라 보여 주는 경우가 많다. 그래서 모든 글자는 위·아래 가장자리에서 각 245px 안쪽(y 245~1105)에 둔다. 가로는 양옆 96px 안쪽.
- 1장(표지)은 프로필 화면에 3:4로 또 잘려 보인다. 정사각형으로 올린 사진을 3:4로 자르면 양옆이 135px씩 더 잘린다. 그래서 표지 글자는 가운데 정렬하고 가로 190~890px 안에만 둔다.
- 장 번호는 넣지 않는다 (인스타그램이 넘김 점을 보여 준다). 의미 없는 구석 장식 글자도 넣지 않는다.
- 이미지를 만든 뒤 브라우저에서 장마다 글자 위치(맨 위·맨 아래 y값)를 재서 위 범위 안에 있는지 확인한다.

## 색과 글꼴
- 사용자가 색을 지정하면 그 색을 쓴다.
- 지정하지 않으면 게시물마다 주제에 어울리는 색을 새로 고른다. 이전 게시물 색을 그대로 쓰지 않는다. 예시:
  - 요리·생활: 따뜻한 크림 + 주황빛 갈색
  - 건강: 연한 초록 + 짙은 초록
  - 정부지원·돈: 연한 하늘 + 짙은 남색
  - 여행: 모래색 + 바다색
  - 스마트폰·AI: 밝은 회색 + 선명한 파랑
- 색은 세 가지로 정한다: 배경, 글자, 강조. 글자는 배경 위에서, 흰 글자는 강조색 위에서 또렷이 읽혀야 한다. 마지막 장이 강조색 배경에 흰 글자이기 때문이다.
- 보라색 그라데이션은 쓰지 않는다.
- 이미지로 만들 때 글꼴은 `assets/fonts` 폴더의 파일만 쓰고, 제목은 가장 굵은 굵기로 쓴다. 폴더가 비어 있으면 사용자에게 글꼴 파일을 넣어 달라고 먼저 말한다.

## 말투
- 따뜻한 존댓말. 60대 독자가 "나도 해 볼까" 싶게.
- 어려운 말은 쉬운 말로 바꾸고, 영어 용어는 처음 나올 때 풀어 쓴다.

## 지키기
- 지어낸 숫자, 통계, 남의 후기, 실존 인물 이야기는 넣지 않는다. 사용자가 준 것만 쓴다.
- 정부지원 금액·신청 기간처럼 바뀔 수 있는 정보는 "확인 필요"로 표시하고, 공식 사이트(정부24, 복지로 등)에서 확인하라고 적는다.
- 겁주거나 과장하지 않는다.

## 저장
- 파일: `carousel/YYYY-MM-DD-제목요약.md`
- 형식:

```
제목: (게시물 제목)
장 수: O장
캡션: (게시물 본문 2~4문장, 마지막에 저장·댓글 부르는 한마디)
해시태그: #태그1 #태그2 ... (10개 안팎)
색: 배경 #...... / 글자 #...... / 강조 #......
---

| 장 | 큰 글자(제목) | 작은 글자(본문) | 화면 구성 |
|---|---|---|---|
| 1 | ... | ... | ... |
| 2 | ... | ... | ... |
```

## 만드는 순서 (2단계)

### 1단계: 문구와 캡션 먼저 확인받기
- 장별 문구, 캡션, 색을 정한다. 색은 배경·글자·강조 세 가지와 고른 이유 한 줄이다.
- md 파일과 `캡션.txt`로 저장한다.
- 대화창에 장별 표, 붙여 넣을 캡션(코드 블록), 색 제안을 보여 준다.
- "이대로 이미지 만들까요?"라고 묻고 멈춘다. 이 단계에서는 이미지를 만들지 않는다.
- 사용자가 고쳐 달라고 하면 고쳐서 다시 보여 준다.

### 2단계: 확인받은 뒤 이미지 만들기
- **기본 틀:** `carousel/2026-10-21-AI첫질문/slides.html`이 사용자가 확인한 최종 디자인이다. 새 게시물은 이 파일을 `carousel/YYYY-MM-DD-제목요약/slides.html`로 복사한다. 그다음 글과, `:root`에 모아 둔 색 값만 1단계에서 정한 색으로 바꾼다.
  - Pretendard 글꼴. 제목은 Black(900), 본문은 Regular·Bold
  - 표지는 가운데 정렬. 나머지 장은 왼쪽 정렬
  - 짧은 강조 막대, 흰 말풍선(실제 입력 문장), 번호 원, 요약 목록
  - 마지막 장은 강조색 배경에 흰 글자
  - 장 번호는 넣지 않는다
- **이미지 만들기:** `node carousel/render.mjs <게시물 폴더> <장 수>`로 PNG를 만든다. 결과는 `01.png`, `02.png` … 이다. 고쳐서 다시 만들 때는 세 번째 값으로 `_수정`을 붙인다.
- **위치 재기:** 만든 뒤 브라우저에서 장마다 글자 위치를 재서 안전 영역(세로 245~1105px, 표지는 가로 190~890px) 안에 있는지 확인한다.
- **눈으로 확인:** PNG를 직접 열어 글자 잘림·겹침·한 글자만 다음 줄로 넘어감·대비를 보고 고친다.
- **표지 확인:** 프로필 화면처럼 3:4로 잘라 본 그림으로 표지가 잘리지 않는지 확인한다.
- 쓰는 프로그램·패키지는 버전을 고정한다 (`latest`, `^` 금지).

## 캡션 모양
- 이미지 폴더 안에 `캡션.txt`로 저장한다. 인스타그램 글쓰기 칸에 그대로 붙여 넣을 수 있는 모양으로 쓴다.
  - 본문 3~5줄 + 빈 줄 + 저장·댓글을 부르는 한마디 + 빈 줄 + 해시태그 10개 안팎
- md 파일의 `캡션:`, `해시태그:`도 같은 내용으로 맞춘다.

## 이미지까지 다 만들고 나면
- 대화창에 다음을 함께 보여 준다.
  - 이미지 몇 장 (표지와 바뀐 장)
  - 이미지 폴더 위치
  - 바로 복사할 수 있는 캡션 (코드 블록)
- 올리는 방법을 한 줄 덧붙인다: 사진을 고를 때 펼치기(↔) 버튼을 눌러 4:5 세로로 올린다.

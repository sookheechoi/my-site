# 글꼴

- Pretendard 1.3.9 (https://github.com/orioncactus/pretendard/releases/tag/v1.3.9)
- 라이선스: SIL Open Font License 1.1 (`Pretendard-LICENSE.txt`)
  - 상업용 사용 가능: 영상·이미지·인스타그램 게시물 등 결과물에 자유롭게 쓸 수 있다.
  - 글꼴 파일 자체만 따로 팔면 안 된다. 파일을 나눠 줄 때는 라이선스 파일을 함께 둔다.
- 들어 있는 굵기: Regular(400), SemiBold(600), Bold(700), ExtraBold(800), Black(900)
- 제목은 가장 굵은 Black(900)을 쓴다.

# 인스타그램 캐러셀

- 인스타그램 캐러셀(여러 장 넘겨 보는 게시물) 문구와 장별 구성을 모아 두는 폴더
- 주제: 시니어프로보노가 알려 주는 정부지원, 일자리, AI·스마트폰 활용법, 건강, 여행, 생활정보 팁 (블로그와 같음)
- 크기: 1080 × 1350 (4:5 세로), 한 게시물 7~10장
- 올릴 때 사진이 정사각형으로 잘리면, 사진 왼쪽 아래의 펼치기(↔) 버튼을 눌러 4:5 세로로 올린다.
- 파일 이름: `YYYY-MM-DD-제목.md` (날짜별). 이미지로 만들면 같은 이름의 폴더에 `01.png`, `02.png` … 로 저장한다. 고쳐서 다시 만들면 `01_수정.png`처럼 이름을 바꿔 옛날 사진과 헷갈리지 않게 한다.
- 확인한 뒤 인스타그램에 직접 올린다.
